# R11：串行正式生成与内存监控

44 号机器对账号执行 CPU 内存 high/max 限制。六个方法同时启动会并发加载模型，可能在 GPU
计算开始前就触发 high。因此正式生成暂时不使用 R10 并行 wave。

每次只运行一个 R9 shard，并在另一个终端运行 `monitor_step_cache_resources.sh`。该脚本汇总
当前账号的 RSS、主机可用内存、每个账号进程的 RSS/CPU 与全部 GPU 显存。默认当账号 RSS 达到
105 GiB 时打印警告，低于管理员提升后的 120 GiB high，给进程清理和采样峰值留出余量。

分片必须在上一任务退出、账号 RSS 回落后才启动下一张卡。GPU 2--7 仍可轮流使用，但不能同时
发起多个模型加载进程。每个成功分片仍是正式 VBench 数据。
